# Contributing / المساهمة

Thanks for improving Redirect Manager. شكرًا لمساهمتك في تطوير المشروع.

1. Use Python 3.10+ and create a focused branch.
2. Keep the runtime dependency-free unless a dependency is clearly justified.
3. Add or update tests for behavior changes.
4. Run `python -m unittest discover -s tests -v` and `python -m compileall -q src tests`.
5. Keep README examples synchronized with the CLI.
6. Never commit credentials, tokens, private URLs, or real production redirect data.

Pull requests should explain the problem, the solution, and validation performed. Bug reports should use synthetic examples where possible.
